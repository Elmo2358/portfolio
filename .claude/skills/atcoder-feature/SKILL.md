# AtCoder Feature Implementation

When implementing AtCoder-related features, follow these steps:

1. **Check existing AtCoder integration code**: Review code in `/atcoder` directory for patterns and existing implementations
2. **Verify database schema**: Check for any new fields needed in the database schema
3. **Implement with TypeScript**: Use Server Components where possible for optimal performance
4. **Test with mock data**: Use mock AtCoder contest data for initial testing
5. **Deploy and verify**: Deploy to production and verify functionality works correctly

---

## Execution

Begin by exploring the existing AtCoder codebase structure, then proceed with feature implementation following the established patterns. Always test with mock data before production deployment.
