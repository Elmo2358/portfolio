# API デバッグワークフロー

このスキルは外部API統合の問題を体系的にデバッグします。

## デバッグ手順

### 1. 認証検証

- 認証トークン/認証情報が有効か確認
- トークンの有効期限が切れていないか確認
- APIキーが正しく設定されているか確認

### 2. レート制限の確認

- レート制限ヘッダーを調査
- キャッシュ戦略が実装されているか確認
- 必要に応じてリトライロジックを追加

### 3. ロギングの追加

- 正確なエラーレスポンスをキャプチャするログを追加
- リクエスト/レスポンスの詳細を記録

### 4. 直接テスト

- curlやPostmanでAPIエンドポイントを直接テスト
- 問題を分離する

### 5. 一般的な問題のチェック

- CORS設定
- リクエストフォーマット
- エラーハンドリング
- タイムアウト設定

## 対象API

- CLIST API
- Notion API
- z.ai API
- UEC Portal API
- その他外部API統合
