# AtCoder テスト・検証ワークフロー

このスキルはAtCoder関連機能の包括的なテストと検証を行います。

## テスト項目

### 1. CLIST API統合の検証

- CLIST APIの認証が正常に動作しているか確認
- レート制限が適切に処理されているか確認
- キャッシュ戦略が有効に機能しているか確認

### 2. コンテストフィルタリングの検証

- AtCoderコンテストのみが表示されているか確認
- Codeforcesなどの他のコンテストが漏れていないか確認
- フィルタリングロジックが正しく動作しているか確認

### 3. データフローの検証

以下の全データフローを確認します：

1. **APIエンドポイント** → `/api/contests` または `/api/clist`
2. **データフェッチング** → APIからのレスポンス
3. **コンポーネントprops** → ContestScheduleや関連コンポーネントへのデータ渡し
4. **クライアントサイドレンダリング** → 最終的なUI表示

### 4. 推薦システムの検証

- 推薦ロジックが正しく機能しているか確認
- ユーザーのパフォーマンスデータに基づいた推薦が行われているか確認

## 実行手順

1. 関連するテストファイルを特定
2. 必要に応じてテストを作成または更新
3. テストを実行
4. 失敗したテストがあれば修正
5. 全てのテストがパスすることを確認

---

## 開始

AtCoder関連機能のテストと検証を開始します。まず、現在の実装状態を確認し、必要なテストを特定します。
