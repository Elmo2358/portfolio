## 日本語

### 拡張機能名
Portfolio Hub

### 簡単な説明（128文字以内）
ポートフォリオサイト「Portfolio Hub」の通知を管理する拡張機能。タスク、就活、AtCoderコンテストのリマインダーをお届けします。

### 詳細な説明

Portfolio Hubは、電気通信大学学生のポートフォリオサイトの通知をChromeブラウザで受け取れるようにする拡張機能です。

## 主な機能

### 🔔 通知機能
- **タスクリマインダー**: タスクの期限が近づくと通知
- **就活リマインダー**: 面接やES提出期限をお知らせ
- **AtCoderコンテスト**: コンテスト開始前に通知

### ⚡ アクションボタン
通知から直接タスクを完了したり、詳細ページを開いたりできます。

### 🎯 自動チェック
- 5分ごとに新しい通知を自動チェック
- 通知はユーザーが操作するまで表示されます

## 使い方

1. 拡張機能をインストール
2. Portfolio Hubサイト（https://elmo2358.net）にログイン
3. リマインダーを設定
4. 通知が届きます！

### 環境切り替え
- ポップアップの「接続先環境」で本番/開発環境を切り替え可能
- 開発環境: http://localhost:3000
- 本番環境: https://elmo2358.net

## プライバシー
- データはブラウザ内のローカルストレージのみに保存されます
- 第三者にデータは共有されません
- 詳しくはプライバシーポリシーをご確認ください

## 対応サイト
Portfolio Hub: <https://elmo2358.net>

## English

### Extension Name
Portfolio Hub

### Short Description (132 characters max)
Manage notifications for your Portfolio Hub site. Get reminders for tasks, job applications, and AtCoder contests.

### Full Description

Portfolio Hub is a Chrome extension that brings notifications from your portfolio site directly to your browser.

## Key Features

### 🔔 Notifications
- **Task Reminders**: Get notified before task deadlines
- **Job Application Reminders**: Stay on top of interviews and application deadlines
- **AtCoder Contests**: Receive notifications before contests start

### ⚡ Action Buttons
Complete tasks or open detail pages directly from notifications.

### 🎯 Auto Check
- Automatically checks for new notifications every 5 minutes
- Notifications remain visible until you interact with them

## How to Use

1. Install the extension
2. Log in to Portfolio Hub site
3. Set up your reminders
4. Receive notifications!

## Privacy
- Data is stored only in your browser's local storage
- No data is shared with third parties
- See privacy policy for details

## Supported Site
Portfolio Hub: <https://elmo2358.net>
