## 🎨 アイコン生成手順

1. ブラウザで `generate-icons.html` を開く
2. 「アイコンを生成」ボタンをクリック（自動生成されます）
3. 各サイズの「ダウンロード」ボタンをクリック
4. `extension/icons/` ディレクトリに保存

**または**: Figma/Illustrator/Canva などで作成

## 📸 スクリーンショット撮影手順

### 推奨サイズ
- **推奨**: 1280x800px または 640x400px
- **形式**: PNG または JPG
- **最大5枚**まで提出可能

### 撮影シーン

1. **通知の受信**
   - タスクリマインダーの通知が表示されている画面
   - 本番環境または開発環境でタスクを作成

2. **アクションボタン**
   - 通知のボタンがクリックできる状態
   - Chromeの通知設定で有効にする必要あり

3. **設定画面**
   - chrome://extensions で拡張機能の詳細
   - またはポップアップ画面（環境切り替えUI含む）

4. **ハブ画面**
   - 本番環境: <https://elmo2358.net/hub>
   - 開発環境: `http://localhost:3000/hub`

## 📦 パッケージ化手順

### ZIPファイル作成

拡張機能ディレクトリから以下のファイルを含めてZIP化：

```
extension/
├── manifest.json
├── background.js
├── popup.html
├── popup.js
├── content.js (不要なら削除可)
└── icons/
    ├── icon16.png
    ├── icon48.png
    └── icon128.png
```

**不要なファイルを除外**:
- `generate-icons.html`
- `generate-icons.js`
- `README.md`
- `.md` ファイル（提出には不要）

## 🔧 本番URL設定

本番環境のURLは既に設定済みです：

- **本番環境**: <https://elmo2358.net>
- **開発環境**: `http://localhost:3000`

ユーザーはポップアップの「接続先環境」から本番/開発環境を切り替え可能です。

manifest.json には以下の権限が既に設定されています：
```json
"host_permissions": [
  "https://elmo2358.net/*",
  "http://localhost:3000/*",
  "http://localhost:3003/*"
]
```

## 🐛 トラブルシューティング

### アイコンが表示されない
- PNG形式であることを確認
- ファイル名が正しいことを確認（icon16.pngなど）

### 通知が動作しない
- Chromeの通知設定で許可されているか確認
- サイトのURLが正しいか確認

### 審査で却下された場合
- プライバシーポリシーが不足していないか確認
- パーミッションが過剰でないか確認
- スクリーンショットが不適切でないか確認
