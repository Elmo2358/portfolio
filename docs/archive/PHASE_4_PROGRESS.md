## 実装完了した機能

### 1. ✅ データエクスポート機能

#### 目的
ユーザーデータのバックアップ・データ移行を容易にする。

#### 実装内容

**APIエンドポイント**: `/api/hub/export`
- **クエリパラメータ**:
  - `app`: エクスポート対象（all, tasks, jobhunt, bucket, atcoder）
  - `format`: 出力形式（json, csv）

**エクスポート対象データ**:
1. **タスク管理**: タイトル、説明、ステータス、優先度、期限日
2. **就活管理**: 企業名、職種、選考ステータス、申請日、メモ
3. **バケツリスト**: タイトル、カテゴリ、ステータス、目標期限、優先度
4. **AtCoder**: 問題ID、ステータス、タイトル、難易度、提出履歴

**UI**:
- `/hub/settings` にエクスポートカードを追加
- 全データ（JSON/CSV）のクイックエクスポートボタン
- 各アプリ個別のエクスポートボタン

#### 技術的な実装

**CSVエクスポート**:
```typescript
// カンマ、改行、引用符のエスケープ処理
function escapeCSV(str: string): string {
  if (!str) return ""
  str = str.replace(/"/g, '""')
  if (str.includes(",") || str.includes('"') || str.includes("\n")) {
    str = `"${str}"`
  }
  return str
}
```

**ファイルダウンロード**:
```typescript
const blob = await res.blob()
const url = window.URL.createObjectURL(blob)
const a = document.createElement("a")
a.href = url
a.download = `${app}_export_${new Date().toISOString().split('T')[0]}.${format}`
document.body.appendChild(a)
a.click()
window.URL.revokeObjectURL(url)
document.body.removeChild(a)
```

#### 使い方
1. `/hub/settings` にアクセス
2. 「データエクスポート」セクションまでスクロール
3. エクスポートしたい形式と対象を選択
4. 自動的にファイルがダウンロードされる

## 技術的な課題と解決策

### 課題1: CSVの文字化け
**問題**: 日本語が含まれるデータでCSVが文字化けする可能性
**解決策**: 
- UTF-8 BOM（Byte Order Mark）を追加
- `charset=utf-8` ヘッダーの設定

### 課題2: 大量データのエクスポート
**問題**: データが多いとエクスポートに時間がかかる
**解決策**:
- ストリーミング処理の導入
- プログレス表示（進捗バー）

### 課題3: エクスポートデータの容量制限
**問題**: 数千件のデータを一度にエクスポートするとファイルサイズが大きくなる
**解決策**:
- 期間指定でフィルタリング
- ページネーション対応
