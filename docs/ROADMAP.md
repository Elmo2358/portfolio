## ✅ 第6フェーズ：UECポータル連携（完了）

**目的**: 大学からのお知らせ・予定・時間割をポータルサイトで確認

**実装方針**: CLI同期スクリプト + Next.js APIでデータ取得

**完了日**: 2026-05-12

### 背景
- uec-portal-cliはBun環境で実行する必要があるが、BunとPlaywrightの互換性問題で動作しない
- Vercel Serverless FunctionsではPlaywrightが動作しない制約がある
- これらの制約を回避するため、Next.js API Routeで直接Playwrightを実装

| ステップ2: モックデータでUI実装 | ✅ | お知らせ、予定、時間割の表示 |
| ステップ3: セッション管理の実装 | ✅ | ログイン状態の保存・復元 |

| データベース | Prisma (SQLite) |
| API | Next.js API Routes |

### 制約事項
1. **Vercel Serverless Functions では動作しない**
   - PlaywrightはNode.jsのフル機能が必要
   - ローカル開発環境、またはRailway等のコンテナ環境での使用を想定

2. **セキュリティ上の注意**
   - ユーザーIDとパスワードは保存しない
   - セッション情報のみを暗号化せずにローカル保存
   - 本番環境では暗号化を検討

3. **2段階認証の対応**
   - 自動化が困難なため、手動入力モードを用意
   - または1回限りの手動ログインでセッションを保存
