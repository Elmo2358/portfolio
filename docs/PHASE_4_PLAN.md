## 第4フェーズの段取り

### ステップ1: Chrome拡張機能の基本実装（1-2日）

#### 目標
Chrome拡張機能の基本的な枠組みを作成し、通知を受け取れるようにする。

#### 実装内容
1. **マニフェストファイル作成** (`extension/manifest.json`)
   ```json
   {
     "name": "Portfolio Hub",
     "version": "1.0.0",
     "manifest_version": 3,
     "permissions": ["notifications", "alarms"],
     "host_permissions": ["http://localhost:3000/*"],
     "background": {
       "service_worker": "background.js"
     }
   }
   ```

2. **Service Worker実装** (`extension/background.js`)
   - 定期的ポーリングで新着通知をチェック
   - 通知クリックで該当ページを開く

3. **Content Script** （オプション）
   - 各ページに通知バッジ表示
   - クイックアクセスボタン

#### 技術的ポイント
- **Chrome Extension APIs**: `chrome.notifications`, `chrome.alarms`
- **Service Worker**: バックグラウンドで定期実行
- **CORS**: サイト側でCORS設定が必要

#### 交付物
- 拡張機能の基本フレームワーク
- 通知の受信と表示
- ローカル開発環境での動作確認

## 技術的な課題と解決策

### 課題1: CORS設定
**問題**: 拡張機能からサイトのAPIを叩くときにCORSエラーが発生
**解決策**:
- `next.config.js`でCORS設定
- APIルートで適切なヘッダー設定

### 課題2: Service Workerの制約
**問題**: Service Worker内でDOM操作ができない
**解決策**:
- chrome.notifications APIを使用
- Content ScriptでUI更新

### 課題3: 認証・セッション管理
**問題**: 拡張機能からサイトのセッションを維持するのが難しい
**解決策**:
- Cookieの共有
- chrome.cookies API
- またはトークンベースの認証
