# Portfolio Hub

電気通信大学情報理工学域Ⅱ類情報通信工学プログラムに2024年入学した学生のポートフォリオサイト＆アプリケーションハブです。

**🌐 本番URL**: https://elmo2358.net

## 機能

### ポートフォリオサイト（公開）
- ホーム - 専攻分野の紹介
- 自己紹介 - 経歴、スキル、趣味
- 資格・試験 - 取得した資格や試験のスコア
- 実習 - インターンシップや実習の経験
- プロジェクト - 制作したプロジェクトや作品

### アプリケーションハブ（認証必要）
- タスク管理 - Google Tasks連携
- UECポータル連携 - 成績・時間割の自動取得
- AtCoder - コンテスト情報・パフォーマンス管理
- Notion - 連携設定
- Claude Settings - API設定

## 技術スタック

- **フレームワーク**: Next.js 14 (App Router)
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS
- **UIコンポーネント**: shadcn/ui
- **データベース**: Prisma + SQLite (開発) / PostgreSQL (本番)
- **認証**: NextAuth.js
